# L3-M06 D07-D09 native Phase6 descriptor binding (nonrelease)

D07, D08, D09 each retain their exact three-component M07 canonical
FeatureBinding identity and per-feature revision/content digest.
Independent P04 detector event set and each descriptor native
valid/total denominator are mandatory. Prepared/Gold support is
MIN once. Missing or unqualified per-descriptor evidence remains
configured but ineligible, not silently dropped or replaced by
UI onset/TS knobs. D09 values are transformed log2 positive times
from native Type7. This adapter does NOT implement the P04 FFT
detector nor certify a current Product Phase6 artifact.
