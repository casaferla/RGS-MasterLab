# L1-M03 playback SRC fixtures

The kernel manifest and coefficient checksums describe the playback-only
44.1/48 kHz assets. The two WAV files are deterministic, synthetic,
redistributable PCM16 stereo listening fixtures derived from the accepted
Task 005 WAV contract. They contain silence followed by:

1. a 440 Hz left-only cue;
2. a 660 Hz right-only cue;
3. both cues together.

Peak level is -24 dBFS. They contain no recorded music and are not release
qualification assets for the future Final Output SRC.
