# L3-M10 — Exact completed-evaluation reuse (nonrelease)

A bounded 800-entry in-memory cache preserves the frozen M10 rule:
only completely attempted, hard-safe, full authoritative candidate
render+analysis+measured-J evidence can be reused without consuming
another attempt. It requires the exact immutable combined generation
snapshot (M05–M11 source/REFERENCE, Fixed, Amount/target, policy),
candidate typed chain execution bytes, canonical M10 parameter
tuple and topology/evidence identity.

No proxy, incomplete M21 scalar, failed/preflight attempt, tolerance
similarity or stale owner snapshot can be inserted or read. Duplicate
same exact key with conflicting measured J/Jtarget/R poisons the
entire generation rather than first-wins. This cannot on its own
attest that a Qt worker actually rendered or published anything;
the Product evaluator remains the owner of authenticity. No
persistence, UI, release or M13 verified status.
